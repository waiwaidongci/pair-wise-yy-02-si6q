# FlowPilot 节点式数据工作流编辑器

基于 React、TypeScript、Vite、React Flow、Ant Design、Zustand、Immer 与 React Router。

## 功能

- 从节点库拖拽数据源、变换、过滤、聚合、双流关联和输出节点。
- 连线时校验输入/输出端口类型，实时拒绝类型冲突和环形依赖。
- 支持框选、复制粘贴、删除、撤销重做、缩略图与依赖层级自动布局。
- 模拟执行按拓扑顺序展示每个节点的运行状态、处理行数和耗时。
- **执行计划固化**：每次运行生成执行计划，保存节点标识、配置版本与连接关系；同层节点并发执行。
- **结果复用与失效**：节点配置或连线变更后，受影响结果立即失效并在下次运行时重算，未受影响的成功结果继续复用。
- **失败恢复**：节点失败后从上一个成功结果恢复，重试后仍失败则取消尚未开始的节点，并在面板展示中断原因。
- **幂等提交**：同一计划（指纹一致）重复提交只写入一次，不产生重复执行。
- **旧版兼容**：打开旧版流程时自动升级，补齐配置版本与执行计划字段。
- 流程保存为 JSON 并可重新导入，执行计划随流程一起导入导出。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```
